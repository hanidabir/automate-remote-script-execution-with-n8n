# اجرای خودکار اسکریپت روی سرور راه‌دور با n8n
*(اجرای زمان‌بندی‌شدهٔ هر دستور یا اسکریپت از طریق SSH)*

این راهنما توضیح می‌دهد که چطور با استفاده از **n8n** بتوانید به هر سرور لینوکسی متصل شوید، اسکریپت یا دستور مورد نظر خود را به صورت زمان‌بندی‌شده اجرا کنید، و در صورت تمایل خروجی آن را برای پردازش بعدی استفاده کنید.

این ورک‌فلو عمومی است و می‌تواند برای هر نوع کار خودکارسازی (مثل بکاپ، مانیتورینگ، پاکسازی و...) استفاده شود.

---

## محتوا در یک نگاه

۱. ساخت کلید SSH در سرور n8n
۲. قرار دادن کلید عمومی در سرور مقصد `/root/.ssh/authorized_keys`
۳. تست اتصال SSH از n8n به مقصد
۴. ایجاد Credential SSH در n8n (Private Key)
۵. ساخت workflow در n8n (Scheduler → SSH Executer → Code Parser) با همهٔ تنظیمات دقیق
۶. تست اجرای دستی و فعال‌سازی خودکار
۷. عیب‌یابی و نکات مهم

---


## پیش‌نیازها

برای استفاده از این سیستم لازم است:

* یک سرور **n8n** (لوکال یا ابری) داشته باشید.
* اسکریپت یا دستوری که قرار است در سرور مقصد اجرا شود آماده باشد.
* [فایل ورک‌فلو](../Remote%20Script%20Runner.json) را از ریپازیتوری دریافت کنید.
---


## ۱ — ایجاد کلید SSH در سرور n8n

**روی سرور n8n (یا دستگاهی که n8n اجرا می‌کند)** اجرا کن:

```bash
ssh-keygen -t ed25519 -C "n8n-ssh-key" -f ~/.ssh/n8n_ssh_key
```

این دو فایل تولید می‌شوند:

* `~/.ssh/n8n_ssh_key`  ← private key
* `~/.ssh/n8n_ssh_key.pub` ← public key

---

## ۲ — افزودن public key به سرور مقصد (root authorized_keys)

**در سرور مقصد** (محل اسکریپت) وارد شو و این کار را انجام بده:

```bash
mkdir -p /root/.ssh
chmod 700 /root/.ssh
# n8n Public Key: cat ~/.ssh/n8n_ssh_key.pub
echo "PASTE_PUBLIC_KEY_CONTENT_HERE" >> /root/.ssh/authorized_keys
chmod 600 /root/.ssh/authorized_keys
```

تست کن از ماشین n8n:

```bash
ssh -i ~/.ssh/n8n_ssh_key root@DESTINATION_SERVER_IP 'echo ok'
# یا
ssh -i ~/.ssh/n8n_ssh_key root@domain.com 'echo ok'
```

باید خروجی `ok` بدون پرسش پسورد برگردد.

---


## ۳ — ساخت Credential اتصال SSH در n8n

۳.۱. وارد **n8n → Credentials → New Credential** شوید.

۳.۲. عبارت **SSH** را جستجو کنید و گزینه‌ی **SSH (Private Key)** را انتخاب کنید.

۳.۳. اطلاعات را به‌صورت زیر پر کنید:

   * **Name:** `remote-server-ssh`
   * **Host:** آی‌پی یا دامنه سرور مقصد
   * **Username:** `root` / هر کاربری که مجاز به اجرای دستور است
   * **Port:** `22`
   * **Private Key:** ssh private key
۳.۴. روی **Save** بزنید و اتصال را تست کنید — باید پیام *Connected successfully* را ببینید.

---

## ۴ — وارد کردن ورک‌فلو در n8n

۴.۱. در داشبورد n8n روی **Import Workflow** کلیک کنید.

۴.۲. فایل [`Remote Script Runner.json`](../Remote%20Script%20Runner.json) را انتخاب کنید.

۴.۳. پس از وارد شدن، ورک‌فلو شامل سه نود اصلی است:

| نود                         | توضیح                                                       |
| --------------------------- | ----------------------------------------------------------- |
| 🕒 **Scheduler (زمان‌بند)** | زمان اجرای خودکار را تعیین می‌کند                           |
| 💻 **Executer (SSH)**       | اسکریپت را روی سرور راه‌دور اجرا می‌کند                     |
| 🧮 **Exporter (Code)**      | خروجی را (در صورت وجود جیسون) تحلیل و آماده‌ی استفاده می‌کند |


### ۴.۴ — تنظیم نودها

- در نود Scheduler، زمانبندی اجرای خودکار را تعیین کنید.
  
- در نود Executer (SSH)، در قسمت **Command** دستور یا نام و آدرس اسکریپت در سرور مقصد را بنویسید؛ به‌طور پیش‌فرض ```bash root\your_script.sh``` تنظیم شده است.

- نود Exporter (Code) برای تحلیل خروجی اسکریپت استفاده می‌شود. اگر اسکریپت شما خروجی JSON تولید کند، این نود آن را به فرمت قابل‌خواندن در n8n تبدیل می‌کند.
در غیر این صورت، فقط خلاصه‌ای از خروجی را برمی‌گرداند.

---

## ۵ — تست اجرای ورک‌فلو

۵.۱. روی **Execute Workflow** کلیک کنید.

۵.۲. خروجی نود **Executer (SSH)** را بررسی کنید — باید محتوای خروجی اسکریپت شما در آن نمایش داده شود.

۵.۳. نود **Exporter**، در صورت موفقیت، داده را به JSON تبدیل کرده و نمایش می‌دهد.

---

## ۶ — فعال‌سازی خودکار

۶.۱. در بالای صفحه روی **Active = ON** کلیک کنید.

۶.۲. از این پس، n8n به‌صورت خودکار طبق زمان‌بندی مشخص‌شده، اسکریپت شما را روی سرور مقصد اجرا می‌کند.

---

## خلاصه اجزا

| جزء                         | توضیح                            |
| --------------------------- | -------------------------------- |
| `Remote Script Runner.json` | فایل ورک‌فلو عمومی n8n           |
| `remote-server-ssh`         | اطلاعات اتصال SSH به سرور مقصد   |
| Scheduler                   | نود زمان‌بندی اجرای خودکار       |
| Executer                    | نود اجرای دستور از طریق SSH      |
| Exporter                    | نود پردازش خروجی و تبدیل به JSON |

## کاربردها

* اجرای خودکار بکاپ‌ها بین سرورها
* پاک‌سازی فایل‌های موقت یا کش
* ریستارت خودکار سرویس‌ها یا کانتینرها
* اجرای اسکریپت‌های مانیتورینگ
* جایگزین ساده و قابل‌مدیریت برای cronjob با رابط گرافیکی
